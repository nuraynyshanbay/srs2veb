# 3-студент — Авторизация, RBAC, IDOR және 17 тест

**Сенің файлдарың:** `authlab/authorization.py` және `tests/test_authlab.py`.

## Не жасадым?

`RBAC` рөлге негізделген рұқсатты тексереді: `/admin/users` маршрутын тек `teacher` аша алады. `IDOR` қорғанысы `notes` кестесіндегі `id` және `owner_id` мәндерін бірге салыстырады: `SELECT ... WHERE id=? AND owner_id=?`. Осылай бөтен жазбаға кіруге болмайды, сервер **404** береді. Студенттің admin бетіне кіруі **403**, оқытушының кіруі **200**. Сонымен қатар `unittest` арқылы 17 қорғаныс сценарийін жаздым.

## Кодтың негізгі жолдары

- `can_view_admin()` — `session['role'] == 'teacher'` тексереді.
- `get_own_note()` — тек өз жазбасына рұқсат береді.
- `add_own_note()` — жаңа жазбаны ағымдағы қолданушыға тіркейді.
- `test_07_role_admin()` — студент/оқытушының құқықтарын салыстырады.
- `test_08_idor_other_note()` — Bob Alice-тің жазбасын ашуға тырысқанда 404 күтеді.
- `test_13_xss_html_escaped()` — енгізілген HTML тегінің экранға қауіпсіз көрсетілуін тексереді.

## Апайға айтатын мәтін

«Мен авторизация мен қауіпсіздік тестілеріне жауап бердім. RBAC көмегімен студенттің әкімшілік бөлімге кіруін шектедім. IDOR-ды тексеру үшін Bob қолданушысымен Alice-тің жазбасын аштым: сервер 404 қайтарады. Бұл жерде ресурс идентификаторымен бірге иесінің идентификаторы тексеріледі. Python unittest арқылы пароль, сессия, CSRF, XSS, SQL injection, RBAC және IDOR бағыттарында 17 тест дайындадым. Олар осы оқу прототипінің таңдалған жағдайларын тексереді, бүкіл интернет қауіпсіздігіне кепілдік бермейді».

## Дәлел ретінде көрсететін команда

```bash
python -m unittest discover -s tests -v
```

Нәтижеде `Ran 17 tests` және `OK` шығуы керек. Жылдам тест режимінде PBKDF2 итерациясын азайту нұсқаулығы README-де көрсетілген.
